# Root cause and behavior

- The old router called `validate_vote` with a non-existent keyword shape, caught every exception and only logged a warning. Tier-1 data could therefore be stored without successful Tier-1 verification.

- The existing identity signature remains mandatory and unchanged. A new optional `tier1_signature_hex` carries the ephemeral-key signature separately; it is required only when the client opts into Tier-1 fields.
- Both keypair modules now return `False` only for expected invalid/malformed client material. Unexpected backend/programming exceptions raise `SignatureVerificationError`, with type-only logging.
