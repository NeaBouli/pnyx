Τι Κάλυψε ο Έλεγχος

  • Next.js 16 web & dashboard
  • Expo / React Native mobile & representative εφαρμογές
  • Κρυπτογραφία: nullifier constructions, Ed25519, Semaphore/Groth16, Arweave
  • Docker / Traefik υποδομή & CI/CD
  • Δημόσιες HTML σελίδες & τεκμηρίωση

Βασικά Ισχυρά Σημεία

Βασική δομή ακεραιότητας ψήφου: Ed25519 gates σε κάθε εγγραφή πολίτη, μοναδικοί DB-anchors κατά διπλής ψήφου, fail-closed σχεδιασμός ZK/Stripe/admin. Ωστόσο, τα ευρήματα EKA-01, EKA-03 και EKA-21 αφορούν υποσυστήματα ψηφοφορίας και παραμένουν ανοιχτά.

  • Δύο CRITICAL ευρήματα του εσωτερικού ελέγχου Μαΐου 2026 (κλειδιά διαχειριστή σε URLs) είναι επαληθευμένα διορθωμένα
  • CORS: ρητό allowlist 5 origins, χωρίς wildcard
  • Stripe webhook: υπογραφή, idempotency, fail-closed
  • Σάρωση ονομάτων αρχείων σε πλήρες ιστορικό git: καθαρή (ανά αναφορά ελέγχου)
